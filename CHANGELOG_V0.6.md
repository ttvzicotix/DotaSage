# DotaSage v0.6 — First Real-Game Test Pass

- Left draft rail now shows both five-hero lineups at once without requiring an inner scroll.
- Locking My Pick no longer opens Game Plan before both teams are full. It stays on Draft and exposes an optional Preview Game Plan button. When both teams become complete, Game Plan opens automatically once.
- Full-team corrections still replace the most recent eligible hero rather than forcing a remove/add dance.
- Browse Roster is now an opaque full-screen workspace beneath the top bar rather than a drawer floating over Pick Advisor.
- Game Plan now shows all 10 heroes with an aggregate draft-relative matchup score: allies vs enemy five, enemies vs allied five.
- Added role-aware Coach Queue with practical lane/map prompts, including conditional pull/stack windows for support roles.
- Item recipe chatter was reduced. Tiny obvious components no longer generate coaching notes. Substantial components can show a compact arrow into a later-phase item; inventory notes are reserved for meaningful actions such as verified disassembly.
- Player Profile now separates OpenDota indexed W/L total, wins, losses and win rate, and clarifies that /wl is not a ranked-only counter.
- Added optional, collapsed post-match feedback. v0.6 stores it locally in the browser only; it is not uploaded.
- Refined the temporary brand mark into an abstract DotaSage rune instead of a DS lettermark.
