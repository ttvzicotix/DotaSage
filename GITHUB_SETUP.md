# GitHub setup

This folder is prepared to become the initial public DotaSage repository.

Recommended repository settings:

- Repository name: `dotasage`
- Visibility: Public
- Initialize with README: No (this project already has one)
- Initialize with .gitignore: No
- Initialize with license: No (this project already includes `LICENSE`)

The first GitHub commit should use v0.16 as the clean baseline. Earlier local
version folders can remain as a separate historical archive rather than being
backfilled into Git history.
