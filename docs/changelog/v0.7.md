# DotaSage v0.7

## Match-ready interaction pass
- Quick Draft now searches all heroes regardless of your selected position.
- Selected position governs Pick Advisor and whether ★ My Pick is eligible.
- Quick Draft shows eight alphabetical heroes before typing and alias-aware matches while typing.
- Search focus is restored after every quick action for rapid draft entry.
- Browse Roster is confined to the center stage, leaving both side rails visible.
- Pick Advisor expands to thirteen visible candidates (one primary + twelve compact).
- Full roster My Pick actions respect the position filter.
- Game Plan item popularity shows up to eight options per phase.
- Added likely early/core/late inventory snapshots and modeled conditional counter-item cards.
- Added role checkpoint timeline.
- Post-match feedback is visible by default rather than collapsed.
- Player Profile adds lazy paginated full public match-history loading with filters and source-count clarity.
