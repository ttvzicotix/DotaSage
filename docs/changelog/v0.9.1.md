# DotaSage v0.9.1

Stabilization patch. No major product-flow redesign.

- Strictly contains the center column so Quick Draft / Pick Advisor cannot paint over Draft Pulse on scaled laptop screens.
- Replaces competing laptop-width rules with a final authoritative responsive layout.
- Makes Pick Advisor shorter: one primary pick + six compact alternatives (Top 7 total).
- Keeps recommendation alternatives in dense grids rather than creating a tall scrolling advisor.
- Adds visible draft context to Pick Advisor (`x/5 enemies · y/5 allies`) so it is clear which entered picks are influencing the ranking.
- Keeps Browse Roster constrained to the center workspace.
- Preserves v0.9 live observed-enemy-item reactions and legal/privacy work.
