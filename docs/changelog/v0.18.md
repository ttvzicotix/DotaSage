# DotaSage v0.18.0

Released: 2026-08-19

## Highlights

- Rebuilt Game Plan into a compact command-center layout instead of a long stack of full-width coaching cards.
- Added a full-field Hero Matchup Atlas for the selected hero using OpenDota matchup history, with every current hero represented, drafted enemies highlighted, search, and A–Z / hardest / best sorting.
- Added explicit split-screen and quadrant viewport resilience so DotaSage reflows instead of shrinking desktop layouts into unreadable columns.
- Fixed small-screen Player Connection / Player Profile rail clipping and reduced the vertical footprint of the connection panel.
- Reduced full-roster mount cost by progressively rendering the hero catalog and using offscreen rendering containment.
- Added item aliases to Enemy Items Observed, including `bm` → Blade Mail, `bkb`, `mkb`, `euls`, `linken`, `sny`, `deso`, `hex`, and other common shorthand.
- Added remembered browser-local player snapshots and a remembered-player switcher, explicit OpenDota refresh, local-data cleanup controls, and clearer fresh/saved/no-history states.
- Added protection against mixing a selected friend profile with a different local Live Sync player.

## Game Plan v2

The active-match page now groups information by decision priority:

1. Hero + draft scores
2. Entered lineups
3. Match context / optional Live Sync
4. 30-second briefing and win condition
5. Lane map
6. Compact threat, matchup, checkpoint, and fight-sequence rail
7. Vision + objective conversion
8. Full-field Hero Matchup Atlas
9. Observed enemy items
10. Item Lab
11. Collapsed post-match review

The full-field atlas reports the selected hero's population win rate against each opponent, public sample size, and a percentage-point matchup edge relative to that hero's weighted field baseline. It is evidence, not a guarantee: role, draft, patch, bracket, and execution still matter.

## Responsive behavior

DotaSage now treats constrained desktop windows as a first-class layout mode. At half-screen, quarter-screen, or short-window dimensions, the application prioritizes readable typography, scrolling, and stacked content rather than preserving the wide desktop grid at unusably small sizes.

## Performance

The Game Plan v2 production JavaScript bundle was reduced relative to the previous production build while the full roster now avoids mounting the entire catalog immediately. Heavy lower-page Game Plan sections also use rendering containment where appropriate.

## Data and privacy

- Remembered player data remains browser-local.
- Live Sync remains opt-in and local to the user's machine.
- DotaSage does not claim access to hidden enemy inventory or a private account-ID live-state API.
- OpenDota matchup and public profile availability is treated separately from local Live Sync state.

## Engineering

- Item recipe namespace normalization and its regression test remain in the release baseline.
- The new responsive rules, Game Plan v2 styles, and matchup atlas styles are isolated in dedicated stylesheets rather than expanding the legacy stylesheet further.
