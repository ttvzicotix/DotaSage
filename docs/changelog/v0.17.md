# DotaSage v0.17

Theme: public-project cleanup, privacy-safe player connection, and release hygiene.

## Player connection
- Added a simple **PLAYER CONNECTION** card in the left rail.
- A player can paste a numeric Dota account ID without creating a DotaSage account.
- The selected account ID is stored only in that browser's local storage.
- Added **DETECT FROM LIVE SYNC** as an optional local identity path.
- The localhost companion derives a public Dota account ID from the current Valve player payload when an account ID or Steam64 identifier is available.
- The hosted site receives only the derived Dota account ID, not the full SteamID.
- Manual Dota ID remains the fallback when the current GSI context does not expose player identity.
- Steam sign-in remains future/optional work for cross-device identity rather than a requirement for basic use.

## Draft controls
- Radiant and Dire are now the visually primary hero actions with larger full-label tap targets.
- My Pick and Ban remain directly available in a smaller secondary row.
- The left-rail Radiant/Dire side selector is larger and easier to hit.
- Older laptop-density rules no longer shrink the primary Quick Draft actions to ant-sized controls.

## Item recipe integrity
- Fixed impossible upgrade-path arrows caused by mixing numeric item IDs, display names, and canonical recipe-component keys.
- OpenDota item constants are now normalized into one canonical internal-name namespace before Game Plan recipe matching.
- Numeric component IDs are resolved to their canonical item keys when necessary.
- Added a regression test covering the exact class of false Linken's Sphere arrows reported from Phase Boots, Power Treads, Blade of Alacrity, Broadsword, and Ogre Axe.
- CI now runs the item-constant regression before the production build.

## Repository cleanup
- Moved historical version notes under `docs/changelog/`.
- Moved current setup/data/privacy/legal/third-party documentation under `docs/`.
- Moved all maintained Windows BAT helpers under `scripts/windows/`.
- Removed redundant launcher wrappers and obsolete GitHub setup notes.
- Removed the stale single-file prototype from the public repository; historical local archives remain outside tracked source.
- Added a small `docs/README.md` index and a durable `docs/roadmap.md`.
- Started incremental stylesheet cleanup under `src/styles/`; the large legacy stylesheet remains in place until visual regression coverage makes a full split safe.
- Moved Player Connection styling out of the component directory.

## Release engineering
- GitHub `main` is connected to Vercel and deploys production automatically.
- Manual Vercel deployment BAT files are no longer part of the release flow.
- Added a GitHub CI workflow that installs dependencies, runs regression checks, builds the Vite app, and rejects reintroduction of the old DraftSage product name.
- Added Vercel Web Analytics integration in the React root.

## Branding, privacy, and contact
- Current product/UI/source naming uses DotaSage.
- Removed personal player seed data and personal fallback initials from public UI source.
- Public source does not hardcode a real Dota account ID or player preferences.
- Added the dedicated public project mailbox `dotasage.contact@gmail.com` to the site and current project documentation.
- Updated current security/privacy documentation to match the v0.17 player-connection and Live Sync boundaries.
